เปิดไฟล์ index.html ด้วยโปรแกรมแก้ไขข้อความ (Notepad++ / VS Code) แล้วเลื่อนไปยังส่วนที่คั่นด้วยคอมเมนต์ /* === ... === */ ตามตารางต่อไปนี้

ตัวแปรรูปแบบข้อมูลระบบจะสร้างโจทย์ให้อัตโนมัติ
level1Data{number: -45} หรือ {number: -45, sum: -4}หาคู่จำนวนเต็มที่คูณกันได้ตาม number (และบวกกันได้ตาม sum ถ้าระบุ)
level2Data{number: -12, min: -15, max: 5}สุ่มคู่ p, q ที่ p·q = number และอยู่ในช่วง [min, max] แล้วสร้างโจทย์แยกตัวประกอบ x² + (p+q)x + number
level3Data{a: -20, b: -7} หรือเพิ่ม op: "<"สร้าง x² + (a+b)x + ab จากตัวประกอบ (x + a)(x + b) → ถ้าไม่ใส่ op เป็น "สมการ" ถ้าใส่ op (<, >, <=, >=) จะเป็น "อสมการ"
level4Data{story, q, choices, answer, hint, why}โจทย์ปัญหาที่เขียนเอง · story ไม่ใส่ก็ได้ · answer เริ่มนับที่ 0

หลักการที่ระบบบังคับใช้อัตโนมัติ

  • ความเป็นแบบทดสอบคู่ขนาน : ข้อที่ i ของ preTestBank และ postTestBank ต้องวัดจุดประสงค์เดียวกัน ระบบจะหยิบข้อลำดับเดียวกันเสมอ
  • การถ่วงดุลตำแหน่งคำตอบ : ระบบสุ่มตำแหน่งเฉลยแบบ Balanced Key Distribution ให้แต่ละตัวเลือก (ก ข ค ง) เป็นคำตอบถูกในสัดส่วนใกล้เคียง 25 % มากที่สุด (25 ข้อ ÷ 4 = 7/6/6/6 และสุ่มว่าตำแหน่งใดได้ 7 ทุกครั้งที่ทำ จึงมีค่าคาดหมายระยะยาวเท่ากับ 25 %)
  • ค่าตัวเลขในโจทย์ : ควบคุมไม่ให้เกิน 300 ทุกข้อ เพื่อให้คำนวณในใจได้เหมาะกับระดับชั้น
  • สัญลักษณ์ : ใช้เครื่องหมายลบทางคณิตศาสตร์ (−) ยกกำลัง (x²) และอสมการ (≤ ≥ < >) อย่างถูกต้องตามมาตรฐาน สสวท.
